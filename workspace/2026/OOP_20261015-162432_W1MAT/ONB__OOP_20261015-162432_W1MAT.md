## 1. Understanding
Разработка и интеграция полного учебного модуля Недели 1 по ООП на сквозном домене транспортной системы Avtobys (Алматы). Модуль предоставляет студентам 2 курса законченный образовательный цикл: теоретическая интерактивная лекция (сравнение Rich vs Anemic модели, сокрытие состояния, свойства `@property` в Python 3.12, диаграммы Mermaid), автопроверяемый квиз по теории (5 вопросов, до 3 баллов), практический тренажер `TransitCard` с автопроверкой через RunnerService (7 автотестов, до 7 баллов) и лабораторную работу №1 `SingleTripTicket` и `Bus` (10 автотестов, до 10 баллов). Итоговый суммарный балл 0..20 сохраняется в таблице `TopicProgress` SQLite со статусом сдачи при $\ge 12$ баллах. Архитектура строго следует принципу Zero-Build (только Vanilla JS, Tailwind CSS CDN и Mermaid.js CDN).

## 2. Entry Points
- `app/content/week_1/` (`lecture.py`, `quiz.py`, `practice.py`, `lab.py`): Контентные модули, банк вопросов и тестовые сьюты заданий.
- `app/services/scoring.py`: Расчет суммарного балла (0..20), правило High-Water Mark ($\max$), персистентное обновление `TopicProgress` и логирование в `Submission`.
- `app/routers/week1.py`: Роуты страницы `/week1` и API эндпоинты (`/api/week1/quiz/check`, `/api/week1/practice/run`, `/api/week1/lab/run`, `/api/week1/progress`).
- `app/main.py`: Регистрация роутера Недели 1 в основном приложении FastAPI.
- `app/templates/week1.html`, `app/static/js/week1.js`: Интерфейс 4 вкладок с сохранением черновиков кода в `LocalStorage`.
- `app/templates/index.html`: Обновление карточки Недели 1 на главной странице дашборда.
- `docs/week1_domain_guide.md`: Инженерное руководство по доменной модели.
- `tests/test_week1_content.py`, `tests/test_scoring.py`, `tests/test_week1_routes.py`: Тестовые наборы ASSURANCE.

Task-owned temporary resources: временные каталоги изолированного выполнения RunnerService (`tempfile.TemporaryDirectory`), автоматически очищаемые после каждого прогона тестов; рабочие материалы создаются в `%TEMP%/tfw/OOP_20261015-162432_W1MAT/` и удаляются перед сдачей.

## 4. Recommendations (suggestions, not blocking)
1. Реализовать автосохранение черновиков в `LocalStorage` при событии `input` с debounce 300мс, чтобы снизить избыточную нагрузку на дисковые операции браузера.
2. Использовать форматированный JSON в ответах API для простоты отладки и наглядного отображения в консоли интерфейса.
3. Предусмотреть в шаблоне класса `SingleTripTicket` дефолтный `issued_at=None` с генерацией `datetime.now()` внутри конструктора для удобства тестирования истечения срока годности билета.

## 5. Risks Found (edge cases, potential issues not in TS)
1. Разница часовых поясов или системного времени сервера при валидации билета: решение должно использовать относительное сравнение `datetime.now() - ticket.issued_at > ticket.valid_duration` без жесткой привязки к абсолютным timestamp.
2. Обработка синтаксических ошибок в студенческом коде (SyntaxError): ASTValidator корректно отлавливает их до исполнения и возвращает понятное студенту сообщение об ошибке.

## 6. Inconsistencies with Code (spec vs reality)
1. Существующий `app/templates/index.html` содержит статическую карточку без динамического отображения баллов за Неделю 1; требуется добавить элементы привязки данных и скрипт запроса `/api/week1/progress`.
