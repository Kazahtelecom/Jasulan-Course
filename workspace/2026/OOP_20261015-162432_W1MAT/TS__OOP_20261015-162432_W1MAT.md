## 1. Objective

Разработать, протестировать и интегрировать в платформу Web-OOP законченный учебный модуль Недели 1 («Основы ООП, инкапсуляция и защита инвариантов») на базе предметной области транспортной системы Avtobys. Модуль оформляется в виде единой веб-страницы с 4 вкладками (`[Лекция]` · `[Квиз]` · `[Практикум]` · `[Лабораторная]`), сохранением черновиков кода в `LocalStorage`, автоматической проверкой решений через `RunnerService` и единым начислением от 0 до 20 баллов в SQLite `TopicProgress` (порог сдачи $\ge 12$ баллов) при строгом соблюдении академической нагрузки 3 часа для второкурсника.

## 2. Scope

### In Scope

1. **Контентный слой Недели 1 (`app/content/week_1/`):**
   - `lecture.py`: Текст лекции по нарративу *Chaos → Structure*, понятия Identiy/State/Behavior, Anemic vs Rich Domain Model, сокрытие данных, синтаксис `@property` в Python 3.12, спецификация инвариантов `TransitCard` и `SingleTripTicket`, интерактивные диаграммы классов и последовательностей на Mermaid.js.
   - `quiz.py`: Структурированный банк из 5 концептуальных вопросов с вариантами ответов, ключами правильности и методическими объяснениями для каждого варианта.
   - `practice.py`: Спецификация и стартовый шаблон класса `TransitCard` (инварианты: неотрицательный баланс, минимальное пополнение 100 ₸, учет скидки при списании, исключения `InsufficientFundsError`, `CardBlockedError`, `InvalidAmountError`), набор из 7 скрытых автотестов pytest (по 1 баллу за тест, до 7 баллов).
   - `lab.py`: Спецификация и стартовый шаблон классов `SingleTripTicket` и `Bus` (инварианты: однократность использования, срок действия 60 минут, исключения `TicketAlreadyUsedError`, `TicketExpiredError`), набор из 10 скрытых автотестов pytest (по 1 баллу за тест, до 10 баллов).
2. **Служба оценивания (`app/services/scoring.py`):**
   - Расчет баллов: Квиз (0..3) + Практикум (0..7) + Лабораторная (0..10) = 0..20 баллов.
   - Персистентное сохранение и обновление в `TopicProgress` (`topic_id="week_1"`, `score`, `is_completed=True` при $\ge 12$ баллах).
   - Политика $\max(\text{old\_score}, \text{new\_score})$: защита от случайного понижения баллов при повторных попытках.
   - Логирование посылок в `Submission`.
3. **Маршрутизация и API (`app/routers/week1.py`):**
   - Страничный эндпоинт `GET /week1` для рендеринга единого интерфейса Недели 1.
   - API `POST /api/week1/quiz/check`: валидация ответов квиза, возврат пояснений и начисление до 3 баллов.
   - API `POST /api/week1/practice/run`: запуск решения `TransitCard` через `RunnerService` против 7 тестов и начисление до 7 баллов.
   - API `POST /api/week1/lab/run`: запуск решения `SingleTripTicket` через `RunnerService` против 10 тестов и начисление до 10 баллов.
   - API `GET /api/week1/progress`: получение текущих баллов и статуса студента.
   - Регистрация `week1_router` в `app/main.py`.
4. **Zero-Build фронтенд (`app/templates/week1.html`, `app/static/js/week1.js`):**
   - Единая адаптивная страница с 4 вкладками: `[Лекция]` · `[Квиз]` · `[Практикум]` · `[Лабораторная]`.
   - Шапка модуля с индикатором текущего балла (`Х / 20 баллов`), бейджем сдачи (В процессе / Сдано) и кнопкой возврата на главную.
   - Клиентская логика Vanilla JS: переключение табов, автосохранение черновиков кода в `LocalStorage`, отправка AJAX-запросов, интерактивный вывод результатов тестов и логов AST-валидатора, рендеринг Mermaid.js диаграмм.
   - Обновление дашборда `app/templates/index.html`: карточка Недели 1 с прогресс-баром и кнопкой перехода.
5. **Тестирование и верификация:**
   - Набор тестов контента `tests/test_week1_content.py`.
   - Набор тестов сервиса оценивания `tests/test_scoring.py`.
   - Набор тестов роутеров и API `tests/test_week1_routes.py`.
   - Руководство по доменной модели в `docs/week1_domain_guide.md`.

### Out of Scope

## 6. Technical Guidance

### 1. Доменные сущности (Рекомендации по реализации)

```python
from decimal import Decimal
from datetime import datetime, timedelta
import uuid

# Исключения
class DomainError(Exception): pass
class InsufficientFundsError(DomainError): pass
class CardBlockedError(DomainError): pass
class InvalidAmountError(DomainError): pass
class TicketAlreadyUsedError(DomainError): pass
class TicketExpiredError(DomainError): pass

class TransitCard:
    def __init__(self, card_id: str, initial_balance: Decimal = Decimal("0"), discount_rate: Decimal = Decimal("0.0")):
        if initial_balance < Decimal("0"):
            raise ValueError("Начальный баланс не может быть отрицательным")
        if not (Decimal("0.0") <= discount_rate <= Decimal("1.0")):
            raise ValueError("Скидка должна быть в диапазоне от 0.0 до 1.0")
        self._card_id = card_id
        self._balance = initial_balance
        self._discount_rate = discount_rate
        self._is_blocked = False

    @property
    def balance(self) -> Decimal:
        return self._balance

    @property
    def is_blocked(self) -> bool:
        return self._is_blocked

    def top_up(self, amount: Decimal) -> None:
        if self._is_blocked:
            raise CardBlockedError("Нельзя пополнить заблокированную карту")
        if amount < Decimal("100"):
            raise InvalidAmountError("Минимальная сумма пополнения — 100 тенге")
        self._balance += amount

    def pay(self, fare: Decimal) -> Decimal:
        if self._is_blocked:
            raise CardBlockedError("Карта заблокирована")
        effective_fare = fare * (Decimal("1.0") - self._discount_rate)
        if self._balance < effective_fare:
            raise InsufficientFundsError("Недостаточно средств на карте")
        self._balance -= effective_fare
        return effective_fare

    def block(self) -> None:
        self._is_blocked = True

    def unblock(self) -> None:
        self._is_blocked = False
```

class SingleTripTicket:

        self.ticket_code = str(uuid.uuid4())
        self.price = price
        self.issued_at = datetime.now()
        self.valid_duration = timedelta(minutes=valid_minutes)
        self.is_validated = False

    def validate(self, bus) -> bool:
        if self.is_validated:

        if datetime.now() - self.issued_at > self.valid_duration:
