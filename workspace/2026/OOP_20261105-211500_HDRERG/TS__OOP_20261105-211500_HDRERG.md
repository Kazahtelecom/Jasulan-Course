## 1. Objective

Реализовать эргономичную систему управления шапкой учебной платформы Web-OOP:
1. Интегрировать комбо-сворачивание: компактный «язычок» (`#header-collapse-handle`) на нижней кромке шапки + явную текстовую кнопку `#header-collapse-toggle`.
2. Перенести кнопку настроек темы `#theme-settings-btn` в верхний ряд к профилю студента.
3. Отвязать правый блок действий от контейнера вкладок и компактно оформить вкладки экзамена, полностью исключив появление горизонтального скролла.

### 5.3 `app/static/js/app.js`
В `applyHeaderCollapseState(isCollapsed)`:
```javascript
function applyHeaderCollapseState(isCollapsed) {
    const header = document.getElementById("main-site-header");
    const label = document.getElementById("header-collapse-label");
    const handleIcon = document.getElementById("header-collapse-handle-icon");
    const handleBtn = document.getElementById("header-collapse-handle");
    if (!header) return;

    if (isCollapsed) {
        header.classList.add("header-collapsed");
        if (label) label.textContent = "▼ Развернуть меню";
        if (handleIcon) handleIcon.textContent = "▼";
        if (handleBtn) handleBtn.setAttribute("title", "Развернуть меню шапки");
    } else {
        header.classList.remove("header-collapsed");
        if (label) label.textContent = "▲ Свернуть меню";
        if (handleIcon) handleIcon.textContent = "▲";
        if (handleBtn) handleBtn.setAttribute("title", "Свернуть меню шапки");
    }
}
```
