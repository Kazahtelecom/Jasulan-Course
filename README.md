# Web-OOP — Мини-LMS по изучению ООП

Веб-проект интерактивного экспресс-курса объектно-ориентированного программирования для студентов 2 курса.

## Цель и North Star проекта

Создать локальную интерактивную образовательную платформу (мини-LMS) на 3 недели изучения ООП:
- **Неделя 1:** От процедурного стиля к объектам, инкапсуляция, отношения между классами (композиция vs наследование), полиморфизм и контракты.
- **Неделя 2:** Принципы проектирования SOLID, связанность и зацепление (Cohesion & Coupling), Dependency Injection.
- **Неделя 3:** Ключевые паттерны проектирования GoF (порождающие, структурные, поведенческие) и основы чистой архитектуры.
- **Экзамен:** Итоговый практический проект/тестирование на базе сквозного домена реального времени (транспортная платежная система Avtobys).

Платформа работает локально, ориентирована на максимальное удобство разработки и сопровождения ИИ-агентами (FastAPI + SQLite + Pytest + современный чистый веб-интерфейс) с автоматической верификацией студенческого кода и подробной документацией архитектуры в `docs/`.

## Быстрый запуск

### Способ 1: В один клик (Windows)
Просто дважды кликните по файлу **`run.bat`** в корне проекта. Он автоматически запустит сервер и откроет платформу в браузере.

### Способ 2: Через терминал (PowerShell / CMD)
В корневой папке проекта выполните команду:
```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
После этого откройте браузер по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000).
