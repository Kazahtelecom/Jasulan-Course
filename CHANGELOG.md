# Changelog — Web-OOP

Все значимые изменения проекта локальной учебной платформы **Web-OOP**, атрибутированные по задачам Trace-First Workflow. Запись в журнале изменений не означает публикацию внешнего релиза.

## [Unreleased]

  - Комплексная миграция всех Jinja2-шаблонов (`tab_home`, `tab_theory`, `tab_practice`, `tab_quiz`, `tab_results`, `exam.html`, `header.html`, обвязка `uml_viewer.html`) и динамических генераторов `app.js` с жестких классов `sky-`, `cyan-`, `amber-` на семантические классы и токены темы.
