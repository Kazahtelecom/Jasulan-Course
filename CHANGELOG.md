# Changelog — Web-OOP

Все значимые изменения проекта локальной учебной платформы **Web-OOP**, атрибутированные по задачам Trace-First Workflow. Запись в журнале изменений не означает публикацию внешнего релиза.

## [Unreleased]

### Added
- **W1MAT (`OOP_20261018-213107_W1MAT`) — 2026-10-18:** Полный редизайн учебного модуля «Неделя 1 · Инкапсуляция» для студентов-новичков (Candidate `79b39aedc52ca4e88a9c5a44568b26f4879e364d`, независимо принят в `REVIEW__OOP_20261018-213107_W1MAT.md`):
  - Интерфейс в стиле **Dark Cyberpunk / Tech Modern** с двухуровневой шапкой («Учебная платформа · Учимся вместе»), переключателем недель и 5 вкладками (`Главная`, `Теория`, `Практика`, `Тестирование`, `Результаты`).
  - 3 кастомные Cyberpunk-иллюстрации (`week1_hero.jpg`, `oop_blueprint.jpg`, `oop_encapsulation.jpg`) вместо рендеринга мелких Mermaid UML-схем на веб-странице (архитектурные схемы сохранены в `docs/domain_model_uml.md`).
  - 4 пошаговых раздела теории с нуля на сквозном классе `SmartCard` и построчный разбор готового кода взаимодействия `Passenger` и `Validator`.
  - Свободный кодовый тренажер из 3 шагов `SmartCard` (`task_1`..`task_3`) с кнопкой «✨ Вставить готовое решение» (`fillSolutionCode`) и нулевым требованием баллов (`0.0` б.).
  - Итоговое тестирование в конце воронки из **10 вопросов по 2.0 балла (`20.0` баллов максимум**, порог зачета $\ge 12.0$ баллов) с защитой лучшего результата High-Water Mark в SQLite (`ScoringService`).
- **CORE (`OOP_20261015-022500_CORE`) — 2026-10-15:** Платформенный фундамент мини-LMS на FastAPI, SQLAlchemy 2.0 (SQLite), изолированной песочнице `RunnerService` (`ASTValidator` + `pytest` в `TemporaryDirectory` с таймаутом 5 с) и Zero-Build фронтенде.
- **INIT (`OOP_20261015-015123_INIT`) — 2026-10-15:** Инициализация проекта `Web-OOP`, исследование исходных материалов курса CS2203 и настройка Trace-First Workflow.
